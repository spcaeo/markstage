Sveltia CMS is a modern rewrite of Netlify/Decap CMS: a fast single-page app with no server and no database, strong translation support and a two-pane editor with live preview. Markstage takes a different path: writers edit on the page, and a server adds staging, roles and a forms inbox.

Who each one is for

Sveltia CMS suits sites that want a free, light editor with nothing to host, first-class multilingual content, and a smooth move from Decap CMS.

Markstage suits teams whose writers should work on the real design, and who need sign-in without a git account, roles, staging and single sign-on. It needs a server. Markstage is pre-release.

Where Sveltia CMS is stronger

  • Nothing to host. No server, no database, no upgrades to install.
  • Translations. Many ways to lay out locales, localized slugs, and per-locale required fields.
  • Mobile. Its docs list mobile support.
  • Formats. YAML and TOML as well as Markdown and JSON.

Moving from Sveltia CMS to Markstage

Sveltia reads Decap-style configuration, so your collections already name their folders. Add the same folders as collections in markstage.config.mjs and add the @markstage/astro integration. Markstage edits Markdown and JSON; keep TOML or YAML data files in Sveltia or convert them. Writers then sign in to Markstage with an email address instead of a git host account.

Frequently asked questions

Is Sveltia CMS free?

Yes. Its site says it is free, with no server and no database.

Does Sveltia CMS work with Astro?

Its README says it works well with Astro and has a showcase of Astro sites. It is not in Astro's own list of CMS guides.

Does Sveltia CMS have visual editing?

It has a live preview beside the form, with click-to-highlight. Editing happens in the form. Markstage edits on the page itself.

Can my writers use Markstage without a GitHub account?

Yes. People sign in to Markstage with an email and password (and two-step sign-in), or through your single sign-on provider. Each save is still a git commit in their name.
