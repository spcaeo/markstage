A Decap CMS alternative for Astro sites

Markstage vs Decap CMS (formerly Netlify CMS): edit on your Astro site's real design, not a form beside a preview. Facts checked 3 Nov 2026.

Facts about Decap CMS checked on 2026-11-03, from its own website. Markstage is not affiliated with it.

Decap CMS, formerly Netlify CMS, is one of the best-known git-based editors. It is a single admin page that talks to your git host. Writers fill in a form, with a live preview beside it. Markstage lets them edit on the page itself.

Who each one is for

Decap CMS suits developers who want a free editor with no server at all, on GitHub, GitLab, Bitbucket and other git hosts, with a large community.

Markstage suits teams whose writers should edit on the site's real design, and who want staging, roles, single sign-on, a forms inbox and SEO checks in the same tool. It needs a server. Markstage is pre-release.

Where Decap CMS is stronger

  • No server to run. Decap is a page that calls your git host's API. Markstage needs Node and git on a server.
  • Many git hosts. GitHub, GitLab, Bitbucket, Azure, Gitea/Forgejo and Git Gateway.
  • Community. About 19.4k GitHub stars and many years of use.
  • Other frameworks. Decap works with any static site generator.

Moving from Decap CMS to Markstage

Your Markdown files stay in the same folders. For each collection in Decap's config.yml, add a collection with the same folder to markstage.config.mjs, then add the @markstage/astro integration. Your media folder can stay where it is (set media.dir). Remove /admin/ when your team has moved.

Frequently asked questions

Is Decap CMS the same as Netlify CMS?

Yes. Decap's own docs call it "formerly Netlify CMS".

Does Decap CMS have visual editing?

It has a real-time preview beside the form, and you can style the preview with your own templates. Editing happens in the form, not on the page.

Does Decap CMS work with Astro?

Yes. Astro's docs have a Decap guide. Off Netlify, the guide says you must create your own OAuth routes, which need on-demand rendering with an adapter.

Is there a Decap CMS alternative that edits on the page?

Markstage does, on your own server for free. CloudCannon and TinaCMS also edit on the page; CloudCannon is hosted only, and TinaCMS can be hosted or self-hosted.

What is Decap Turbo?

A paid hosted layer on top of Decap: hosted sign-in and roles, a proxy against git host rate limits, a content store and site variables. Free for 1 site and 1 seat; Pro is €19 a month.
