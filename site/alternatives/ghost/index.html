Ghost is a mature publishing platform with its own editor, themes, newsletters and paid memberships. Many Astro sites use it headless: writers work in Ghost's admin, and Astro reads the posts through Ghost's Content API. Markstage takes the other road: writers edit on the Astro site itself, and the content stays as Markdown and JSON files in your git repository.

Who each one is for

Ghost suits publications: a blog or a magazine that wants newsletters, memberships and paid subscriptions built in, with its own themes, run on your own server or on Ghost(Pro). It has many years of production use and a large community (55.7k stars on GitHub on 4 November 2026).

Markstage suits Astro sites whose writers should edit on the site's real design, where content belongs in git next to the code, and where staging, roles and single sign-on should come included. Markstage is pre-release.

Where Ghost is stronger

  • Newsletters, memberships and paid subscriptions in the same tool as the posts.
  • A hosted service. Ghost(Pro) runs it for you; Markstage needs a server you look after.
  • Years of use and a large community, with a theme marketplace and many integrations.
  • A permissive licence. Ghost's code is under the MIT licence.

Moving from Ghost to Markstage

Ghost exports posts, pages, tags, tiers and settings as one JSON file (Settings, then Advanced, then Import/Export), and members as a CSV file. Markstage has no Ghost importer yet; one is coming in 0.4.0 (roadmap). Today its import API takes entries and media as JSON: a dry run first, then the run, as drafts, and running it again only updates what changed (it remembers each source id, such as the Ghost post id). Turn each Ghost post into the import's shape, with its body as Markdown, and the pictures come in through the same import.

Writers then find familiar ideas: author profiles with co-authors, drafts, scheduled publishing, a check before a post goes live, roles with the same names, a media library and revisions. Newsletters and paid memberships have no Markstage equivalent; keep Ghost or another tool for those.

Frequently asked questions

Can I use Ghost with Astro?

Yes, as a headless CMS. Astro's docs have a "Ghost & Astro" guide that reads posts through Ghost's Content API with the @tryghost/content-api client. Writers keep using Ghost's own editor.

What is the best Ghost alternative for an Astro site?

It depends on what you use Ghost for. If it is newsletters and paid memberships, Ghost does them well and Markstage does not. If it is the writing and editing, Markstage gives writers an editor on the Astro site itself, with content in git. The two other products people weigh most often have pages too: WordPress and Prismic, and the comparison puts all four side by side.

Does Markstage need MySQL like Ghost?

No. Content stays as files in git. One SQLite file, built into Node.js, holds people, sessions, the inbox, drafts in progress and the audit log, so there is no database server to run.

Is Markstage free like Ghost?

Both are free to self-host. Markstage is source-available under the Elastic License 2.0: you may not offer it to others as a hosted service without a commercial licence.
