A TinaCMS alternative for Astro sites

Markstage vs TinaCMS for Astro: edit on your site's real design, keep content in git, self-host free with no database server. Checked 3 Nov 2026.

Facts about TinaCMS checked on 2026-11-03, from its own website. Markstage is not affiliated with it.

TinaCMS and Markstage both keep your content as files in git and both let people edit on the page. They differ in what you run, what it costs and what the editor covers beyond the page.

Who each one is for

TinaCMS suits developers who want click-to-edit on their pages, MDX, and a hosted backend (TinaCloud) or a self-hosted one. It works with Astro, Next.js and other frameworks.

Markstage suits teams with an Astro site whose writers should work on the real design, and who want staging, roles, single sign-on, a forms inbox and releases included, on their own server, for free. Markstage is pre-release.

Where TinaCMS is stronger

  • MDX. TinaCMS edits MDX; Markstage edits Markdown and JSON only.
  • A hosted option. TinaCloud runs the backend for you. Markstage needs a server you look after.
  • Many frameworks. TinaCMS supports more than Astro. Markstage's only adapter today is Astro.
  • A large community. TinaCMS has about 13.9k stars on GitHub and years of use.

Moving from TinaCMS to Markstage

Your Markdown and JSON files stay where they are. List the same folders as collections in markstage.config.mjs, add the @markstage/astro integration, and mark the fields your components show so they can be edited on the page. MDX files are not edited by Markstage, so keep them in TinaCMS or convert them to Markdown first. When you are ready, remove the tina() integration and the island routes. Run the Markstage server with Docker Compose or systemd and nginx; see the deploy guide.

Frequently asked questions

Is there a free TinaCMS alternative for Astro?

Yes. Markstage is free to self-host, with no per-user fees, and edits Astro sites on their real design. TinaCMS itself is also free to self-host, but it then needs a database adapter, and its hosted plan is free for two users.

Does TinaCMS work with Astro?

Yes. TinaCMS has an Astro guide and an @tinacms/astro integration with visual editing. Its docs say visual editing needs server output and an adapter, or every editable region wrapped in <TinaIsland>.

Can Markstage edit MDX like TinaCMS?

No. Markstage edits Markdown with front matter and JSON. If your site depends on MDX components, TinaCMS or Keystatic fits better.

Do I need a database to self-host?

TinaCMS's self-hosted backend uses a database adapter (its docs name MongoDB and Postgres) as a cache of your files. Markstage needs no database server: one SQLite file holds people, sessions, the inbox, drafts in progress, trash, releases, the media index and the audit log; the content stays in git.

Which one has staging?

Markstage has local, staging and production built in, each a git branch plus a server. TinaCMS has an editorial workflow on protected branches with pull requests and preview links, on its Team plan and up.
