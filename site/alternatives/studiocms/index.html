StudioCMS vs Markstage: which fits your Astro site?

StudioCMS is a server-rendered Astro CMS with a database; Markstage keeps content in git and edits on the real page. Facts checked 3 Nov 2026.

Facts about StudioCMS checked on 2026-11-03, from its own website. Markstage is not affiliated with it.

StudioCMS is a headless CMS built for Astro, with its own dashboard, plugins and renderers. It runs with your Astro site in server mode and keeps content in a database. Markstage keeps content as files in git and leaves the live site static.

Who each one is for

StudioCMS suits Astro sites that already render on a server and want a dashboard CMS inside the project, with a libSQL, MySQL or PostgreSQL database.

Markstage suits sites that want content in git, a static live site, and writers editing on the real design. Markstage is pre-release.

Where StudioCMS is stronger

  • Built only for Astro, with a dashboard and plugins in the project itself.
  • Several renderers, including MDX and Markdoc.
  • No separate server beyond your server-rendered Astro site.

Frequently asked questions

Does StudioCMS need a database?

Yes. Its getting-started guide asks for a libSQL, MySQL or PostgreSQL connection and an Astro adapter.

Can Markstage work with a static Astro site?

Yes. Markstage runs next to the site as its own server and adds editing markup only in editor mode, so the production build is unchanged.
