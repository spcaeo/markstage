Frequently asked questions

What Markstage is, what it costs, where it runs and how it treats your files, answered in plain words.

Common questions

What is a visual editor for Astro?

An editor where writers change an Astro site's content while looking at the site itself: its own components, fonts and layout, not grey form fields. Markstage shows the real page, lets people type text where it appears, and puts other settings (an image's alt text, a link, a section's options) in a side panel.

Does Astro have a built-in CMS or editor?

No. Astro's docs describe a CMS as a separate tool that "lets you write content and manage assets outside of your Astro project", and list many to choose from. Astro's content collections give your Markdown, MDX, YAML and JSON files a schema and type safety, but not an editing screen.

Is Markstage free?

Yes, to self-host. You may use, copy, change and run it for free, in your business and for your clients' sites. There are no per-user, per-site or per-language fees. The one thing you may not do without a commercial licence is offer Markstage to others as a hosted or managed service.

Is Markstage free software under an OSI licence?

It is not open source in the OSI sense. Markstage is source-available under the Elastic License 2.0: the code is public, and you may run and change it for free, with the one limit above.

How is Markstage different from a headless CMS?

A headless CMS keeps your content in its own database, usually hosted, and your site reads it through an API. Markstage keeps content as Markdown and JSON files in your git repository, and the Astro site reads them like any other files. There is no content database and no content API to depend on.

How is it different from other git-based editors?

Most git-based editors (Decap CMS, Sveltia CMS, Keystatic, Pages CMS) show a form, sometimes beside a preview. Markstage edits on the page. CloudCannon and TinaCMS also edit on the page: CloudCannon is a hosted service, and TinaCMS can be hosted or self-hosted. Markstage also includes staging, roles, single sign-on and a forms inbox at no cost. The full comparison has the details and sources.

Do I need a database?

Not for content: that stays as files in git. One SQLite file on the server (the SQLite built into Node) holds people, sessions, the inbox, drafts in progress, trash, releases, the media index and the audit log. There is no database server to install.

What do I need to self-host it?

Node.js 22.13 or newer and git, on a server next to your site. The deploy guide covers Docker Compose, or systemd and nginx without Docker.

Does my Astro site have to use server rendering?

No. Markstage's editing markup appears only in editor mode, so your production build stays exactly as it is and can stay fully static.

Does Markstage support MDX?

No. Markstage edits Markdown with front matter and JSON. If your site depends on MDX components, TinaCMS, Keystatic or Outstatic fit better today.

Can people without a GitHub account edit?

Yes. People sign in to Markstage with an email and password, with optional two-step sign-in, or through your single sign-on provider (OpenID Connect). Each save is still a git commit in their own name.

Is Markstage ready for production?

Markstage is pre-release and in active development. It is built and tested against a real 460-page Astro site, but most other products in this space have years of production use. Check the changelog and try it on a copy of your site first.

Who makes Markstage?

How Markstage works

What is Markstage?

Markstage is a visual editor for Markdown and JSON content sites. Writers edit on the site’s own design instead of in form fields, and every save is a clean git diff of exactly what they changed (with the Markstage server, a commit in their name). Its first adapter is Astro.

Which frameworks does Markstage support?

Astro today, through the @markstage/astro integration. The core (the document model and the Markdown converter) has no framework in it, so other adapters can follow.

Will Markstage rewrite my Markdown files?

Only the blocks you change. Opening and saving a file with no edit leaves it byte for byte the same, and moving a block and moving it back gives an identical file, so a review shows exactly what moved.

Can an AI agent edit my site through Markstage?

An agent that speaks the Model Context Protocol can read the site and draft changes as the person whose token it holds. It never publishes, deletes or promotes anything on its own: a person reviews its release and puts it live.
