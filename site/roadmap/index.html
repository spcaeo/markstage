Markstage roadmap

Markstage is pre-release (0.x): a minor version may still change how things work. This page lists what is being built now for the next release and what is planned after it. We promise no dates beyond that.

Every "Coming in" or "Planned" badge on the comparison pages links here. The mark beside it is always what Markstage does today.

Have a need that is not here? Open a feature request.

Planned, later

  • Packages on npm Planned

    Install @markstage/astro from npm, without a clone of the repository.

  • The real page on the server, too Planned

    The built editor on a server draws each article inside its real page, as astro dev does today.

  • More than one server process Planned

    Sign-in and share-link limits shared between processes, so one data dir can run on several.

  • Adapters beyond Astro Planned

    The core has no framework in it; more site generators after Astro.

  • Live co-editing Planned

    Several people in one page at once, with live cursors, beside today's locks and three-way merge.

  • AI translation of a whole site Planned

    Draft every page of a site in another language in one run, for people to review.

  • AI link and SEO suggestions Planned

    Suggested internal links and fixes for search problems, for a person to accept.

  • A stable 1.0 Planned

    After deeper quality, security and performance work.
