Markstage roadmap

Markstage is pre-release (0.x): a minor version may still change how things work. This page lists what is being built now for the next release, 0.4.0, and what is planned after it. We promise no dates beyond that.

Every "Coming in 0.4.0" or "Planned" badge on the comparison pages links here. The mark beside it is always what Markstage does today.

Have a need that is not here? Open a feature request.

Being built now, for 0.4.0

  • MDX editing Coming in 0.4.0

    Edit the prose of MDX files on the page; code and components stay locked, shown as cards.

  • Import from WordPress, Ghost and Prismic Coming in 0.4.0

    Bring posts, pages, media, authors and redirects across from WordPress, Ghost or Prismic.

  • A ready server image Coming in 0.4.0

    A Docker image of the Markstage server, built and tested by CI.

  • A starter site Coming in 0.4.0

    An Astro blog with Markstage already set up, to start a new site from.

  • A live demo Coming in 0.4.0

    Try the editor on a sample blog in your browser, with no sign-up.

  • AI writing help on the page Coming in 0.4.0

    Rewrite, shorten or fix the grammar of a selection; the writer accepts or rejects each change, and nothing saves by itself.

  • More AI providers Coming in 0.4.0

    Any OpenAI-compatible endpoint, and local models such as Ollama, beside Anthropic.

  • An MCP publish tool Coming in 0.4.0

    An AI agent may ask to publish, and the site's publish rules decide, as they do for a person.

Planned, later

  • Packages on npm Planned

    Install @markstage/astro from npm, without a clone of the repository.

  • The real page on the server, too Planned

    The built editor on a server draws each article inside its real page, as astro dev does today.

  • More than one server process Planned

    Sign-in and share-link limits shared between processes, so one data dir can run on several.

  • Adapters beyond Astro Planned

    The core has no framework in it; more site generators after Astro.

  • Live co-editing Planned

    Several people in one page at once, with live cursors, beside today's locks and three-way merge.

  • AI translation of a whole site Planned

    Draft every page of a site in another language in one run, for people to review.

  • AI link and SEO suggestions Planned

    Suggested internal links and fixes for search problems, for a person to accept.

  • A stable 1.0 Planned

    After deeper quality, security and performance work.
