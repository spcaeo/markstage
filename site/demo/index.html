Try Markstage in your browser

The real Markstage editor on a sample Astro blog, with no sign-up and nothing to install. Edit a post on its own page, save it, and see the git diff the save would commit. Nothing is sent anywhere: your edits stay in this browser tab.

Open the live demoSee the sample blogInstall it for real

What you can do in the demo

  • Open any post of the sample blog, drawn on its own page with the blog’s design
  • Type on the page: headings, lists, links, tables, the block menu (/) and the toolbar
  • Switch to Source mode and edit the Markdown as written
  • Press Save and see the git diff the save would commit, changing only what you changed
  • Look around: Home, Blog posts, the publish checks, History, the Library, Site settings

What needs a running install

These open in the demo so you can see them, and each change says “Not in the demo: install Markstage to try this”, with a link to the install steps:

  • Publishing and scheduling
  • Releases and environments
  • Users, roles and sign-in
  • Settings changes
  • Uploads and the media library
  • AI suggestions

How the demo works

It is the same editor a Markstage server serves, built as static files. What a server would answer when the editor reads (the posts, the lists, the checks) was recorded from a real server running the sample blog. A save runs Markstage’s own Markdown writer in your browser, so the file text and the diff are what a server would commit. The strip at the top of the editor has Your changes and Reset demo.
