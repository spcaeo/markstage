This is a small [Astro](https://astro.build/) blog with Markstage already set up. Every post is a Markdown file in
`src/content/posts/`, and the editor writes back to those files, so your content stays plain text in your own
git repository.

## Write on the page

Run `npm run dev` and open `/markstage/` on the dev server. Pick a post and type straight onto the page: the
editor draws it with this site's own CSS, so what you see is what a reader gets. Saving rewrites only the blocks
you changed.

## Make it yours

- Change the name in `src/layouts/Base.astro` and `markstage.config.mjs`.
- Change the colours and fonts in `src/styles/site.css`.
- Set your address in `astro.config.mjs` (`site`).
- Delete these posts, or keep them as notes.

> The editor in `npm run dev` has no sign-in and listens on this machine only. For a team, run the Markstage
> server next to the site: sign-in, roles, history and publishing.
