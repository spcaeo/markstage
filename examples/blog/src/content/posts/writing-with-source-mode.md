Switch to **Source** in the header to edit the frontmatter and the Markdown directly. A save there checks the
version like the canvas does, so two people never overwrite each other.

## On the canvas

For editing on the page itself, start with [the guide](/posts/hello-markstage/).

### Shortcuts

The same keyboard shortcuts work in Source mode and on the canvas, so nothing new is needed to switch between them.

- ⌘K opens the search; with text selected it adds a link.
- ⌘S saves.
