# Getting help with Markstage

Markstage is free to self-host and made by a small team at Space-O Technologies. There is no paid support, but we
read everything.

1. **Read the docs.** [README.md](README.md) says what Markstage is, [docs/CONFIG.md](docs/CONFIG.md) how to set a
   site up, [docs/DEPLOY.md](docs/DEPLOY.md) how to run the server, and [docs/WRITING.md](docs/WRITING.md) how a
   writer does each everyday job. In the editor, **Help (?)** in the top bar has the same guide.
2. **Ask in Discussions.** How-to questions, ideas and show-and-tell:
   <https://github.com/spcaeo/markstage/discussions>.
3. **Report a bug.** Use the bug form in [Issues](https://github.com/spcaeo/markstage/issues/new/choose). Say which
   version you run (the release line in the editor's footer, or `markstage-server version`). Never paste passwords,
   tokens, API keys, session cookies or a real person's data: use `example.com` addresses and made-up accounts.
4. **Security problems** go privately, as [SECURITY.md](SECURITY.md) describes, never in a public issue.
5. **A commercial licence** (for example, to offer Markstage as a hosted service): open an issue titled
   "Commercial licence", as [NOTICE](NOTICE) says.
